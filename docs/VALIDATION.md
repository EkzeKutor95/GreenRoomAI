## Makefile и часовой перезапуск — 20.11.2026

Makefile поддерживает GNU Make 4.x + PowerShell на Windows и POSIX shell на macOS/Linux. Добавлены справка по умолчанию, безопасный `make init`, запуск собранного бинарника через `make run` и непрерывный процесс без перезапусков через `make run-once`. Проверено, что `init` создаёт файл по шаблону и сохраняет существующий `.env` без изменений; проверка использовала только синтетическую временную папку внутри проекта.

По умолчанию supervisor запускает новый процесс бота через 1h работы предыдущего. EOF управляющего stdin вызывает штатную отмену, затем supervisor обязательно ждёт завершения и освобождения lock. Родитель не загружает `.env`, поэтому каждый дочерний процесс читает файл заново. Ctrl+C завершает supervision. Ошибочный ранний выход и таймаут остановки возвращают ошибку; после принудительного Kill следующий процесс не создаётся, lock не удаляется предположением. Ошибка освобождения lock также возвращается наверх.

В `cmd/greenroom` добавлена Ginkgo/Gomega suite для EOF, открытого канала, ошибки чтения и отмены. `internal/supervisor` проверяется синтетическими дочерними процессами: последовательные старты без перекрытия, завершение при отмене, отсутствие запуска после предварительной отмены, ранний exit0/ошибка, ошибка старта, зависание с Kill+Wait и отсутствие повторного запуска. Конструктор проверяет зависимости и положительные интервалы.

Успешно выполнены `make check`, `make test GOFLAGS=-race`, `make build` и `make windows`. Отдельные CLI smoke checks подтвердили одноразовые version/demo/check-config, отказ при отрицательном интервале и отсутствие цикла запусков при неверной конфигурации. Выполнены default/help и dry-run команды Makefile для обеих платформ; `plutil -lint` примера launchd прошёл. Нативного Windows/PowerShell на проверочном Mac нет: Windows exe собран, его выполнение на Windows и обработка Ctrl+C именно из Windows GNU Make здесь не проверялись.

Боевой бот и внешние API в этой проверке не запускались. Реальный `.env` и рабочее техническое состояние не изменялись.
